# Тошкент Трейд — продажи (Bklit UI)

Дашборд продаж на React + Tailwind + графиках Bklit UI.

## Запуск
1. Установите Node.js (LTS) с nodejs.org.
2. В папке проекта:
   npm install
   npm run dev
3. Откройте http://localhost:5173

## Обновить данные
Данные лежат в src/data.json (zones — план/факт по зонам, period — рабочие дни, lines — продажи по категориям и маркам).
Пришлите новый All_Dashbord — пересоберу data.json.

## Сборка сайта
npm run build  → готовые файлы в папке dist/

## Приложение на телефон
Папка dist/ — готовое приложение (PWA). Разместите её на любом хостинге с https
(например, перетащите папку на app.netlify.com/drop), откройте ссылку на телефоне и:
- Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран»;
- iPhone (Safari): «Поделиться» → «На экран „Домой“».
После установки приложение открывается с иконки и работает без интернета.
Свежий отчёт: кнопка «Загрузить All_Dashbord» → выбрать .xlsm из Telegram/Файлов.
